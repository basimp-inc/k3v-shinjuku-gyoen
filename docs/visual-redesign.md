# Visual Redesign — 世界観と見せ方の再設計

方針: **和解案** — CLAUDE.md の「気取らない親しみやすさ」は残し、
高級感の作り方だけを **配色 → Typography / 余白 / 素材 / 精度** に置き換える。
写真は未入手のため、**正しいアスペクト比のプレースホルダーで構図を確定**し、
写真が届いた時点で差し替えるだけで完成する状態にする。

---

## 1. 診断 — なぜ「AIが作った一般的なホテルサイト」に見えるのか

印象論ではなく、コードの実測値。

| 指標 | 実測 | 帰結 |
|---|---|---|
| `mx-auto max-w-6xl` | **23箇所** | 全セクションが同じ幅の中央寄せ。full-bleed が1つも無い |
| 見出しの実効サイズ | デスクトップで**2種類だけ**（`text-3xl` が14中13、`text-2xl` が1） | Scale Contrast が存在しない |
| 最大の文字 | Hero の `3.1rem`（50px） | 「Huge / Small」の Huge が無い |
| eyebrow の文字列 | `font-en text-xs tracking-[0.25em] text-(--color-accent)` が**16ファイルで一字一句同一** | セクションの個性がゼロ |
| 「eyebrow＋h2＋lead＋3列カード」 | **完全一致が4セクション**、見出し3点セット一致が10セクション | 「また同じカードが出てきた」の正体 |
| `rounded-full` | **37箇所** ／ `rounded-[18px]` 15箇所 | 硬い面・シャープなエッジが1つも無い |
| セクション縦余白 | `py-20 md:py-28` か `py-16 md:py-24` の**2値のみ** | Spatial Contrast が無い |
| 非対称レイアウト | **1箇所**（Hero の `md:grid-cols-[1.05fr_1fr]`）のみ | 他は全て均等分割 |
| 要素の重なり | **2箇所**（モバイルナビ中央ボタン、地図のキャプション）のみ | レイヤー表現が無い |
| セリフ体 | **0** — 3書体すべて丸ゴシック（Zen Maru Gothic / M PLUS Rounded 1c / Quicksand） | Vintage / Editorial と構造的に両立しない |
| 写真 | **0枚**（`public/` はNext.jsの初期SVGのみ、全ビジュアルがinline SVG） | 「その空間にいる感覚」が原理的に出せない |

**結論**: 配色は原因ではない。原因は
**①版面が1種類 ②文字サイズが2種類 ③全部が丸い ④余白が2値 ⑤写真が無い**の5つ。

## 2. 参考資料の読み取り（Gaia Brick / 木目 / デニム）

届いた資料は参考**サイト**ではなく**実物の建材サンプル**だった。ここから設計に効く事実:

- **Gaia Brick HOA(赤)/HOY(焼過)** — 壁が「レンガに見える」いちばんの理由は目地でも赤さでもなく、
  **一枚ごとの焼きムラ（個体差）**。単色ベタ＋目地格子では絶対に出ない。
  → プロトタイプでは **16枚それぞれに別の色**を割り当て、各煉瓦の上端に光・下端に影を1pxずつ入れた。
- **積み方は破れ目地（running bond）**。`repeating-linear-gradient` の交差では
  芋目地にしかならずタイルに見える。行ごとの半コマ位相差が要るので inline SVG `<pattern>` で実装。
- **目地は白すぎない生成り**で、煉瓦高さの約1/10と太い。
- **木目（柿渋・チーク・アンティークオーク）** — 5案の色域はこの実物サンプルと整合していた。
- **デニム** — 45°の綾織りと、縦方向に流れるストーンウォッシュのムラが明確。

## 3. 新しいビジュアル言語

### 3-1. Typography（最大の変更）

| 役割 | 書体 | サイズ |
|---|---|---|
| 大見出し（和文） | **Shippori Mincho B1** | `clamp(1.9rem, 4.4vw, 3.75rem)` |
| ディスプレイ（欧文のみ） | **Cormorant Garamond** | `clamp(3rem, 7.2vw, 6.5rem)` |
| 本文 | **M PLUS Rounded 1c**（現行維持＝親しみやすさの担保） | `0.9375rem` |
| ラベル | **Jost**（letterspacing `.34em`） | `0.6875rem` |

**注意点（実装で必ず踏む地雷）**:
- 和文は全角なので**欧文と同じ `vw` 係数だと破綻する**。11文字 × 122px = 1340px になり Hero が溢れた。和文用と欧文用でスケールを分けること。
- `max-width` の **`ch` 単位は欧文 "0" 幅（≒0.5em）基準**。全角の和文では約半分の幅で折れてしまい、
  「時間が積み重なっ／た」のような不正な改行になる。和文見出しでは `ch` 値をおよそ2倍にする。

### 3-2. 形（角丸の再配分）

- **大面積（帯・写真・パネル・カード）は直角**にする — 現行の `rounded-[18px]` を全廃。
- **角丸はピル型ボタンとチップだけに残す** — ここが「気取らなさ」の担保になる。

### 3-3. Contrast

- **Color**: 極暗面 `#241512`（espresso）を新設。cream `#fdf7f0` との差で画面を殴る。
- **Scale**: ラベル11px ↔ ディスプレイ104px。約9.5倍のレンジ。
- **Spatial**: セクション縦余白を `s-tall / s-mid / s-tight` の3段に分け、
  Hero末尾には極端に密な数値帯を置いて「密 ↔ 疎」を作る。
- **Material**: 煉瓦（粗）↔ 生成りパネル（平滑）↔ 写真（階調）を隣接させる。
- **Typographic**: 明朝の大見出し ↔ 丸ゴシックの本文 ↔ letterspaced な極小ラベル。

### 3-4. Section Rhythm（「また同じカード」を殺す）

| # | セクション | 役割 | 構成 |
|---|---|---|---|
| 01 | Hero | Dramatic・High contrast | 極暗面。写真が右上に抜ける非対称。縦組みブランド銘。末尾に密な数値帯 |
| 02 | Concept | Editorial・Vintage | 紙。巨大な袋文字「01」に写真を重ね、本文は右へオフセット＋狭い版面。細罫の引用 |
| 03 | Rooms | Photography-focused | **3室を3通りの構図で**。01=写真が左端に抜ける／02=反転＋上にずらす／03=full-bleed 21:9に文字を重ねる |
| 04 | Material | 素材そのもの | 煉瓦の壁。文字は壁に乗せず、生成りパネルが影を落として浮く |
| 05 | Location | Urban・Informational | 極暗面。細罫の密なデータ表 ↔ 大きな写真 |
| 06 | CTA | Strong contrast | 煉瓦の壁。欧文ディスプレイ1行 |

### 3-5. Materiality

「赤茶色の背景」ではなく**壁**として扱う。プロトタイプで実装済み:
- 16枚の個体差 + 各煉瓦の稜線ハイライト/陰
- **斜光**（左上からの `radial-gradient`）と下方向の落ち影
- パネルの `box-shadow` が壁に落ちる = 奥行き
- 表面の粒子（`feTurbulence` を `overlay` で合成）— これが無いとベクターの清潔さが残り焼き物に見えない

**技術的な落とし穴**: `<svg>` は置換要素なので `position:absolute; inset:0` **だけでは既定の 300×150 のまま**になる。
`width:100%; height:100%` を明示しないと壁が左上の小片にしか描かれない（実際に踏んだ）。

### 3-6. Photography

写真が主役になる前提でレイアウトを確定済み。必要なカットとアスペクト比:

| 用途 | 比率 | 内容 |
|---|---|---|
| Hero | 3:4（縦・右上に抜ける） | 客室の窓辺、朝の光 |
| Concept | 4:5 | 朝のリビング、生活の痕跡 |
| Room 01 | 5:4 | UNICO の部屋 |
| Room 02 | 4:5 | JOURNAL STANDARD FURNITURE |
| Room 03 | 21:9（full-bleed・文字を重ねる） | CRASH GATE |
| Location | 16:11 | 御苑の並木と街の表情 |

プレースホルダーには粒子とトンボを入れてあるので、**写真が来る前でも構図の良し悪しは判断できる**。
