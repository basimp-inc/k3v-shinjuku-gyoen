## 共通のページ構成（6案すべて同一）

**6案は「同じ中身を、6通りのデザインで見る」ためのもの。** 構成とコンテンツは6案で完全に揃え、
違うのはビジュアルの方向性だけ、という状態にしてある。

セクションは現行TOPページと同じ6つ・同じ順序で固定：

```
Hero → PrimeLocation → Renovated → Amenities → Rooms → Access
```

- **文言は6案とも共通の名前空間から読む**（`hero` / `primeLocation` / `renovated` /
  `amenities` / `rooms` / `access`）。案ごとの文言は持たない＝ズレようがない。
  各案の名前空間（`gyoen` / `denim` / … ）に残っているのは、ナビ・フッター・
  ティッカーなど**装飾とクロームだけ**。ナビのラベルは共通の `mockNav`。

### 見出しの組み方（英字ディスプレイ＋和文サブヘッド）

5案（gyoen / denim / timber / chambray / kraft）は元々 **Latin の display 書体**
── Fraunces / Instrument Serif / Barlow Condensed / Archivo Black ──
が各案の顔だった。これらは**和文グリフを持たない**ため、共通化した和文見出しを
そのまま流し込むと書体差が消える。そこで各セクションの組みはこうしてある:

```
01 — PRIME LOCATION      小さいモノスペースの通し番号＋ラベル（正典の eyebrow）
Green on One Side.       大きい英字ディスプレイ（案ごとの書体・案ごとの文言）
新宿御苑まで徒歩6分、       和文見出し＝サブヘッド（正典・6案共通）
暮らしに必要なものは…
```

英字ディスプレイ行（`<design>.display.*`）は**書体を見せるための装置**であって
情報ではない。徒歩分数・室数・料金などの事実は一切載せないので、正典の和文と
食い違いようがない。ja/en/zh とも同じ英文＝翻訳対象ではない。
生成スクリプトは [add-mockdisplay-messages.py](./add-mockdisplay-messages.py)。

**doma-ceramic だけ英字ディスプレイを持たない。** この案の `--dsp` は
Zen Maru Gothic 900 ＝和文書体で、「和文主導・明朝禁止・光沢禁止」がこの案の
主張そのもの。ここに大きな英字を足すと、6案で唯一「和文で始まる案」が消える。
- **変えてよいのはビジュアルだけ**：配色・書体・余白・レイアウト・画像の扱い・素材表現・
  装飾・階層・UIの作り。
- レイアウトは `app/mock-structure.css` に6案ぶんまとめてある。素材・配色・書体は
  各 `app/<name>-design.css`（モックHTMLから生成したもの）が引き続き担当。
  この分離のおかげで、生成物側に手を入れずに構成だけ揃えられている。

> 旧構成（Concept / Experience / Material / CTA など案ごとにバラバラだったもの）は廃止。
> `docs/top-page-mock-*.html` は**素材・配色・書体の出典**としては有効だが、
> **セクション構成は上記が正**で、モックHTMLとは一致しない。

## gyoen-green

- **素材**: 木（ローズウッド〜チーク）`#7a3f1f`。縦方向の木目ヘアライン＋148pxごとの板継ぎを、カード地のセクション帯にごく薄く敷く。
- **主要色**: bg `#f2efe6` / card `#eae6d9` / accent `#33502f`（深緑） / accent2 `#7a3f1f`（木） / line-strong `#58809e`（デニム） / text `#1e2a1c`
- **狙い**: 新宿御苑の樹木の深緑を「主役の構造色」に据えた唯一の案。空/デニム `#a9c3d6` は罫線・ラベルなど小面積、芝 `#93b23e` はイラストの差し色に限定し、面は木とオフホワイトで持たせる。
- **出典**: TOPページモック [top-page-mock-5.html](./top-page-mock-5.html)。TOPページはこのモックを丸ごと再現（`app/gyoen-design.css` + `app/[locale]/_components/gyoen/`）。下層ページには配色のみ適用。

## denim-sakura

- **素材**: デニム（本物の綾織り）。45°のツイル＋スラブノイズ、生成りのステッチ、耳（セルビッジ）、織りネーム、洗濯タグ。淡いシャンブレーと生デニムの2種を使い分ける。
- **主要色**: bg `#dee9f0` / card-deep `#a8c6d9`（デニム） / accent `#4a6b3e`（御苑の緑） / accent2 `#b87c9b`（桜） / micro `#93b23e`（芝） / text `#16241c`
- **狙い**: gyoen-green と主役／脇役がちょうど逆で、**寒色が面を支配する唯一の案**。空とデニムの `#a8c6d9` が全体の地、緑は深さとコントラストを作る2セクションだけ、芝の `#93b23e` はドット・チェック・矢印などごく小面積に限定。
- **桜の扱い**: `#e6b8CC` を装飾ではなく**構造**として使う。デニムの耳は本来「赤耳」だが、それを桜色に置き換え、画像の端・フッター・ヒーローのレールに走らせている。面としての桜は「一日の過ごし方」セクションの1枚だけ。
- **出典**: TOPページモック [top-page-mock-6.html](./top-page-mock-6.html)。TOPページはこのモックを丸ごと再現（`app/denim-design.css` + `app/[locale]/_components/denim/`）。下層ページには配色のみ適用。

## kraft-riso（Mock 09・実装済み／スイッチャー6段目）

- **素材**: 紙とインク。クラフト紙の繊維（横方向 turbulence）／45°ハーフトーン網点（8pxピッチの2重格子）／版ズレ（`text-shadow` で全ページ同一方向・同一量）／段ボール（縦フルート）。
- **主要色**: 地 `#e0d0b4` クラフト ／ 薄口 `#efe6d4` ／ 段ボール `#c9b492` ／ インク3色 = 緑 `#00a95c`・橙 `#ff6c2f`・青 `#3d5588` ／ 墨 `#2b2621`
- **狙い**: 既存4案（gyoen-green / denim-sakura / timber-indigo / washed-chambray）は素材が「布か木」、配色が「デニム＋木＋緑＋生成り」に全案共通で固定されていた。本案はそこから外れる**唯一の暖色・高明度・印刷物**の案。クライアントの「チープシック／気取らない／高級感NG」に最も直接効く。
- **構造**: **3室 = 3インク**。ROOM 01 unico = 緑、ROOM 02 JSF = 橙、ROOM 03 crash gate = 青。色が装飾ではなくページの編成原理になっている。重ね刷り（multiply）で4色目が出る点も Ink セクションで明示。
- **インク運用ルール（コントラスト検証済み）**:
  | 面 | 置ける文字 | 比 |
  |---|---|---|
  | クラフト地 | 墨 / 青 / green-dp `#005c32` / orange-dp `#9a320c` | 9.88 / 4.85 / 5.37 / 4.88 |
  | 緑ベタ | 墨 | 4.87 |
  | 橙ベタ | 墨 | 5.31 |
  | 青ベタ | 紙色 `#efe6d4` | 5.94 |

  **明るい緑・橙は面と大判文字のみ。本文には使えない**（クラフト地に対し 2.03 / 1.86）。リソグラフの実際の挙動と一致する制約。
- **書体**: Archivo Black（ディスプレイ）／ Archivo（UI）／ IBM Plex Mono（ラベル・図版キャプション）／ Zen Kaku Gothic New（和文）。セリフ体は不使用。
- **出典**: [top-page-mock-9.html](./top-page-mock-9.html)。セクション構成は mock-08 と同一（hero / concept / rooms / experience / ink / location / book）。mock-08 の「4つの素材」セクションを「3つのインク」に置換。
- **実装**: `app/kraft-design.css` + `app/[locale]/_components/kraft/`（`KraftTop.tsx` / `KraftBehaviour.tsx` / `scenes.ts`）。アセットは `docs/gen-kraft-assets.py`、文言は `docs/add-kraft-messages.py`（3言語177キー）で生成。SVG id と keyframes は `kr-` 名前空間、セクション id は `kr-` 前置（他デザインと同一DOM上に共存するため）。下層ページには `[data-theme="kraft-riso"]` の配色のみ適用。

## doma-ceramic（Mock 10・実装済み／スイッチャー7段目）

- **素材**: 土と釉。和紙（簀の目＋糸目＋繊維ムラ）／三和土（骨材を散らした床、目地なし）／マット釉薬（**縁に溜まって下が濃くなる** inset shadow＋低周波の釉ムラ）／籐の編み目。**光沢はどこにも使わない** ── マットであることが「高級旅館化」を防ぐ最大の条件。
- **主要色**: 和紙 `#f2ede1` ／ 薄美濃紙 `#faf6ec` ／ 粉引 `#e4dac6` ／ 三和土 `#a99177`・土間影 `#6f5c48` ／ 織部 `#5c7052` ／ 飴釉 `#9a5622` ／ 鉄釉 `#3a332c` ／ 墨 `#26221f` ／ 竹 `#b99c63`
- **狙い**: 既存案で唯一「新宿御苑＝日本庭園」を**素材の側から**拾う案。旅館回避のために2つ縛りを入れている ──
  1. **明朝・セリフ体を一切使わない**。見出しは Zen Maru Gothic 900 の**和文主導**（角丸＝気取らなさ、クライアント方針の「角丸歓迎」に直結）。欧文は小さく添えるだけ。
  2. **角丸を大きく取り、余白は詰め気味**。広く空けたグリッドは高級感に寄るので、器が並んだ棚くらいの密度にする。
- **構造**: **3室 = 3つの釉**。ROOM 01 unico = 織部、ROOM 02 JSF = 飴釉、ROOM 03 crash gate = 鉄釉。素材セクションは「三つの釉と、その下の土」で、4枚目に三和土を置く。
- **釉薬運用ルール（コントラスト検証済み）**:
  | 面 | 置ける文字 | 比 |
  |---|---|---|
  | 和紙 / 粉引 | 墨 | 13.51 / 11.38 |
  | 和紙 / 粉引 | 織部 4.62・飴釉 4.82・土間影 5.45 | ─ |
  | 織部・飴釉・鉄釉のベタ面 | **紙色 `#faf6ec` のみ** | 5.00 / 5.22 / 11.52 |
  | 三和土 `#a99177` | 墨 | 5.26 |

  **釉薬のベタ面はすべて紙色文字**（器の内側は暗い）という単一ルールで通る。中間トーンで墨文字を受けられるのは三和土だけ。飴釉は当初 `#a8632c` だったが紙色に対し 4.34 で基準を割るため `#9a5622` に調整。
- **書体**: Zen Maru Gothic 900（見出し・和文主導）／ Zen Kaku Gothic New（本文）／ Archivo・IBM Plex Mono（欧文ラベル）。**明朝なし**。
- **出典**: [top-page-mock-10.html](./top-page-mock-10.html)。セクション構成は mock-08 と同一（hero / concept / rooms / experience / material / location / book）。
- **実装**: `app/doma-design.css` + `app/[locale]/_components/doma/`（`DomaTop.tsx` / `DomaBehaviour.tsx` / `scenes.ts`）。アセットは `docs/gen-doma-assets.py`、文言は `docs/add-doma-messages.py`（3言語173キー）で生成。SVG id と keyframes は `dc-` 名前空間、セクション id は `dc-` 前置。見出しの「新宿御苑」は言語ごとに位置が変わるため titleA/titleEm/titleB/titleC の4スロットに分割。下層ページには `[data-theme="doma-ceramic"]` の配色のみ適用。

## kissa-tile（Mock 11・未実装／モックHTML削除済み）

- **素材**: 硬くて艶のあるもの。20mm角モザイクタイル（目地2px・5×5=110pxで一巡させ一枚ずつ色をずらす）／ホーロー（上端の硬いハイライト＋下端の厚み＋角の欠け）／ヘアラインステンレス（細い横線＋広いつや）／ミントタイル。**シリーズ唯一の「艶あり」**で、総マットの案B（doma-ceramic）のちょうど裏返しになる。
- **主要色**: タイル地 `#efeae2` ／ 目地 `#cfc7b8`（線用）・`#e5ded2`（面用） ／ ミント壁 `#8fb0a3` ／ ホーロー赤 `#c1352c` ／ ステンレス `#8e8b84`・濃 `#4a4843` ／ 御苑グリーン `#456b5c` ／ クリームソーダ `#f0c34a` ／ 墨 `#241f1c`
- **狙い**: 「新宿御苑前という**まち**」の生活感。昭和から続く喫茶店・銭湯の材質をそのまま部屋に持ち込む。CRASH GATE のインダストリアルモダンと最も噛み合う。
- **提案時のトレードオフとその処理**: 「ミント壁は昭和喫茶の壁であって御苑の緑ではない → 自然のモチーフが痩せる」問題に対し、**御苑グリーン `#456b5c` を壁のミントとは別に系へ残した**。植え込み・見切り・素材セクション4枚目・CTAはすべてこの色で受けるので、緑のモチーフは弱くならない。
- **構造**: **3室 = 3つの面**。ROOM 01 unico = ミント壁、ROOM 02 JSF = ホーロー赤、ROOM 03 crash gate = ステンレス。
- **面の運用ルール（コントラスト検証済み）**:
  | 面 | 置ける文字 | 比 |
  |---|---|---|
  | タイル地 | 墨 12.9 / ホーロー赤 4.60 / 御苑緑 5.00 / ステン濃 7.63 | ─ |
  | ホーロー赤ベタ | 白 | 5.51 |
  | ミント壁ベタ | 墨 | 6.92 |
  | 御苑緑ベタ | 白 | 5.45 |
  | ステン濃ベタ | 白 8.32 / クリーム 5.48 | ─ |
  | クリームベタ | 墨 | 9.79 |

  **クリームソーダ `#f0c34a` は明るい地の上では文字にできない**（タイル地に対し 1.39）。面・縁取り・暗い面の上の数字に限定する。
- **書体**: Dela Gothic One（見出し＝ホーロー看板の書き文字）／ Zen Kaku Gothic New（本文）／ Archivo・IBM Plex Mono（欧文ラベル）。角丸は 4px に抑える（タイルなので角を立てる＝案Bの器とは逆）。
- **出典**: `top-page-mock-11.html`（未採用のため削除済み）。セクション構成は mock-08 と同一。
