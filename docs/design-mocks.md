## 共通のページ構成（2案とも同一）

**2案は「同じ中身を、2通りのデザインで見る」ためのもの。** 構成とコンテンツは揃え、
違うのはビジュアルの方向性だけ、という状態にしてある。

セクションは現行TOPページと同じ6つ・同じ順序で固定：

```
Hero → PrimeLocation → Renovated → Amenities → Rooms → Access
```

- **文言は2案とも共通の名前空間から読む**（`hero` / `primeLocation` / `renovated` /
  `amenities` / `rooms` / `access`）。案ごとの文言は持たない＝ズレようがない。
  各案の名前空間（`gyoen` / `chambray`）に残っているのは、ナビ・フッター・
  ティッカーなど**装飾とクロームだけ**。ナビのラベルは共通の `mockNav`。

### 見出しの組み方（英字ディスプレイ＋和文サブヘッド）

2案（gyoen / chambray）とも **Latin の display 書体** ── Fraunces /
Barlow Condensed ── が顔になっている。これらは**和文グリフを持たない**ため、
共通化した和文見出しをそのまま流し込むと書体差が消える。
そこで各セクションの組みはこうしてある:

```
01 — PRIME LOCATION      小さいモノスペースの通し番号＋ラベル（正典の eyebrow）
Green on One Side.       大きい英字ディスプレイ（案ごとの書体・案ごとの文言）
新宿御苑まで徒歩6分、       和文見出し＝サブヘッド（正典・2案共通）
暮らしに必要なものは…
```

英字ディスプレイ行（`<design>.display.*`）は**書体を見せるための装置**であって
情報ではない。徒歩分数・室数・料金などの事実は一切載せないので、正典の和文と
食い違いようがない。ja/en/zh とも同じ英文＝翻訳対象ではない。
生成スクリプトは [add-mockdisplay-messages.py](./add-mockdisplay-messages.py)。

- **変えてよいのはビジュアルだけ**：配色・書体・余白・レイアウト・画像の扱い・素材表現・
  装飾・階層・UIの作り。
- レイアウトは `app/mock-structure.css` に2案ぶんまとめてある。素材・配色・書体は
  各 `app/<name>-design.css`（モックHTMLから生成したもの）が引き続き担当。
  この分離のおかげで、生成物側に手を入れずに構成だけ揃えられている。

> 旧構成（Concept / Experience / Material / CTA など案ごとにバラバラだったもの）は廃止。
> `docs/top-page-mock-*.html` は**素材・配色・書体の出典**としては有効だが、
> **セクション構成は上記が正**で、モックHTMLとは一致しない。

## gyoen-green

- **素材**: 木（ローズウッド〜チーク）`#7a3f1f`。縦方向の木目ヘアライン＋148pxごとの板継ぎを、カード地のセクション帯にごく薄く敷く。
- **主要色**: bg `#f2efe6` / card `#eae6d9` / accent `#33502f`（深緑） / accent2 `#7a3f1f`（木） / line-strong `#58809e`（デニム） / text `#1e2a1c`
- **狙い**: 新宿御苑の樹木の深緑を「主役の構造色」に据えた唯一の案。空/デニム `#a9c3d6` は罫線・ラベルなど小面積、芝 `#93b23e` はイラストの差し色に限定し、面は木とオフホワイトで持たせる。
- **出典**: TOPページモック [top-page-mock-5.html](./top-page-mock-5.html)。TOPページはこのモックを丸ごと再現（`app/gyoen-design.css` + `app/[locale]/_components/gyoen/`）。下層ページには配色のみ適用。

## kissa-tile（Mock 11・未実装／モックHTML削除済み）

- **素材**: 硬くて艶のあるもの。20mm角モザイクタイル（目地2px・5×5=110pxで一巡させ一枚ずつ色をずらす）／ホーロー（上端の硬いハイライト＋下端の厚み＋角の欠け）／ヘアラインステンレス（細い横線＋広いつや）／ミントタイル。**シリーズ唯一の「艶あり」**で、総マットの案B（doma-ceramic）のちょうど裏返しになる。
- **主要色**: タイル地 `#efeae2` ／ 目地 `#cfc7b8`（線用）・`#e5ded2`（面用） ／ ミント壁 `#8fb0a3` ／ ホーロー赤 `#c1352c` ／ ステンレス `#8e8b84`・濃 `#4a4843` ／ 御苑グリーン `#456b5c` ／ クリームソーダ `#f0c34a` ／ 墨 `#241f1c`
- **狙い**: 「新宿御苑前という**まち**」の生活感。昭和から続く喫茶店・銭湯の材質をそのまま部屋に持ち込む。CRASH GATE のインダストリアルモダンと最も噛み合う。
- **提案時のトレードオフとその処理**: 「ミント壁は昭和喫茶の壁であって御苑の緑ではない → 自然のモチーフが痩せる」問題に対し、**御苑グリーン `#456b5c` を壁のミントとは別に系へ残した**。植え込み・見切り・素材セクション4枚目・CTAはすべてこの色で受けるので、緑のモチーフは弱くならない。
- **構造**: **3室 = 3つの面**。ROOM 01 unico = ミント壁、ROOM 02 JSF = ホーロー赤、ROOM 03 crash gate = ステンレス。
- **面の運用ルール（コントラスト検証済み）**:
  | 面 | 置ける文字 | 比 |
  |---|---|---|
  | タイル地 | 墨 12.9 / ホーロー赤 4.60 / 御苑緑 5.00 / ステン濃 7.63 | ─ |
  | ホーロー赤ベタ | 白 | 5.51 |
  | ミント壁ベタ | 墨 | 6.92 |
  | 御苑緑ベタ | 白 | 5.45 |
  | ステン濃ベタ | 白 8.32 / クリーム 5.48 | ─ |
  | クリームベタ | 墨 | 9.79 |

  **クリームソーダ `#f0c34a` は明るい地の上では文字にできない**（タイル地に対し 1.39）。面・縁取り・暗い面の上の数字に限定する。
- **書体**: Dela Gothic One（見出し＝ホーロー看板の書き文字）／ Zen Kaku Gothic New（本文）／ Archivo・IBM Plex Mono（欧文ラベル）。角丸は 4px に抑える（タイルなので角を立てる＝案Bの器とは逆）。
- **出典**: `top-page-mock-11.html`（未採用のため削除済み）。セクション構成は mock-08 と同一。

## Phase 1.5 — クライアントfeedback反映（2026-08-17）

7案のうち **washed-chambray** と **gyoen-green** の2案に絞り込み。この2案に指摘を反映し、あわせて全案共通で不足していた「立地の利便性」「部屋別の設備」を追加した。不採用の4案（denim / timber / kraft / doma）は一切変更せずに `~/workbench/design-mock-library` へ退避し、その後リポジトリから撤去した（Phase 1.6）。

### 追加した共通コンテンツ

`app/[locale]/_components/mockShared.tsx` に `MockConvenience` / `MockFacilities` を追加し、chambray と gyoen の2案が描画する。文言は既存ネームスペースへの**追加のみ**（`primeLocation.convenience` / `amenities.facilities`）で、既存キーは1つも変更していない。

- **立地の利便性** — 「一般的な民泊は閑散とした住宅地だが、ここは深夜でも買い物ができ、新宿三丁目・歌舞伎町まで歩ける」をPrimeLocationの下に。
- **部屋別の設備** — 305 / 401 / 503 の設備と全室共通設備をAmenities内に。⚠️ 部屋番号とブランド3室の対応は未確定のため、**番号のみで表示**しブランド名との紐付けはどこにも書いていない。確定したら `messages/*.json` の `amenities.facilities.rooms[].room` だけを直す。

CSSは各案のスコープ内（`app/mock-structure.css` の `.chambray-top` / `.gyoen-top` ブロック）に別々に持たせている。gyoen の `.mock-conv` は暗緑地の `.loc` セクション内に入るため、見出し・リード文だけ地に合わせて明色に反転させてある（そのままだと `--green` の見出しが同色の地に載って消える）。

### 2026-08-17 レビューで比較した2点（いずれも確定済み・切り替えは廃止）

washed-chambray には一時期 `?wcRail=` / `?wcFooter=` の切り替えがあったが、どちらもクライアント確認が済み、属性ごと削除して既定に一本化した。

- **近隣SHOPの見せ方** — 「4コママトリックス vs 横スライド」への回答は**横スライド維持**。2026-08-21 に**オートディスプレイで統一**。カード列を必要な数だけ複製して継ぎ目なくループする（複製は `aria-hidden`）。ポインタが乗っている間・フォーカス中・タブ非表示中は停止し、`prefers-reduced-motion` では動かない。実装は `app/[locale]/_components/chambray/autoRail.ts`（Chambray Gyoen も同じ挙動）。
- **最終セクションの地** — 指摘は「色が重い／白字が細い」。塗り壁 / ウッド / モケットグリーンの3案を比較し、2026-08-22 に**カジュアルなウッド調で確定**。地と柄は `app/wood.css` の全デザイン共通ウッド（`#CC8043`・板の継ぎ目つき）で、本文コントラストは 5.4:1。**地を明るくして文字を濃いインクに反転**させる構造で「重い／細い」を解いており、透明度で階層を作るのはやめ、サイズ・ウェイト・字間で差をつけている（旧実装は薄い白文字で階層を作っていたのが「細い」の正体）。

### gyoen-green

頭出しの立体感・構図は高評価につき変更せず、**ヒーローを切り取るウッドの見切り（`.ledge`）の面だけ**を胡桃 `#3e251a` からハニーオーク `#C89055` に変更。徒歩分数のキャプションは、明るくなった地の上ではクリーム文字が約1.9:1になるため濃いインクに反転している。
